Read `guides/playbooks/labs-accept.md` in this repository and follow it step by step. Check the role and
`labs_member` in `.harness/profile.json` (run `./harness whoami` if it is missing). `./harness labs accept` only
writes `accept.sh`; run it only when the person says so, after they have read it.
