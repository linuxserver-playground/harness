name: contract-change
description: Run a cross-repo change (image.yml field, record.json, API shape) as an ordered change train with a tracking issue. Use when a change spans builder, hub, site or control.

Read `guides/playbooks/contract-change.md` in this repository and follow it step by step. Check the role in
`.harness/profile.json` (run `./harness whoami` if it is missing) and take that role's path through the
playbook. Draft anything that would be filed or posted; the person approves it.
